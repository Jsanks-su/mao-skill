# MAO Skill 战略修复文档

## 这次对话暴露的问题

用户一开始问的是名字和头像，但真实问题不是命名问题，而是一个弱者进入 AI 内容红海时如何选择战略位置的问题。

现有 MAO skill 在使用时把问题压成了：

- 名字哪个更好记。
- 头像是否适合长期 IP。
- 账号名、口播名、视觉符号如何统一。

这些回答不是完全错，但层级错了。它们解决的是表层战术，没有先解决战略问题：

> 一个没有资源优势的新个人 IP，如何在已经拥挤的 AI 内容战场里建立局部优势？

用户期待的 MAO 不是“现实建议助手”，而是“战略参谋”。它应当先找战场、找主要矛盾、找敌我力量、找以少胜多的打法，再让名字、头像、内容形式服从战略。

## 用户真实预期

用户对 MAO skill 的预期可以概括为：

> 不跟着表面问题跑，而是升维判断真正的主要矛盾，给出战略出口，并把弱者如何以少胜多讲清楚。

更具体地说，用户希望 MAO 能做到：

1. 识别表层问题背后的真实战场。
2. 不急着回答用户抛出的第一个细节。
3. 先判断强者在哪里、红海在哪里、用户的弱者优势在哪里。
4. 给出可占领的局部阵地。
5. 用战略推导战术，而不是用战术拼凑战略。
6. 对用户的想法有独立判断，不只是在用户给出的选项里做选择题。

这和现有 skill 的目标是一致的，但现有 SKILL.md 没有足够强地把这些动作变成默认行为。

## 现有 Skill 的结构性缺口

### 1. “轻量回答”权重过高

现有 SKILL.md 反复强调“优先轻量”“普通回答 2 到 5 段”“不要都做成报告”。这能防止装腔作势，但副作用是：当用户提出战略问题的一个局部症状时，模型容易过早给短建议。

这次对话里，用户问名字和头像，模型就按“命名建议”处理了，而不是先判断这是个人 IP 冷启动中的战略定位问题。

修复方向：

> 轻量不是低层。即使输出简短，也必须先完成战略层判断；不能因为回答轻量就跳过主战场、主要矛盾和弱者优势。

### 2. “主要矛盾”没有强制前置

现有 SKILL.md 有判断骨架：

```text
事实 -> 不确定处 -> 主要矛盾 -> 阶段 -> 力量/资源 -> 路线 -> 小行动 -> 反馈 -> 修正
```

但它只是“内部按这个顺序思考”，没有规定遇到复杂经营问题时必须先做“问题重构”。

这导致模型会把用户的问题原样接受。例如用户问“名字是什么”，模型就回答名字，而不是先问：

- 你要打的内容战场是什么？
- 你相对大号的非对称优势是什么？
- 名字要服务哪个战略位置？

修复方向：

> 对创业、品牌、增长、竞争、组织类问题，先判断用户问的是“症状”还是“根因”。如果是症状，必须先重构问题，再给答案。

### 3. “弱者对强者路线”没有被调度

仓库里已经有 `references/application/weak-to-strong-strategy.md`，内容是对的：

- 强者最容易碾压什么？
- 强者忽略什么？
- 弱者在哪里有速度、亲密、信任、本地性或专注优势？
- 哪些仗绝不能打？
- 哪个小胜利会改变下一阶段？

但主 SKILL.md 没有要求在“竞争、IP、冷启动、增长、创业方向”中优先调用这张卡。

这次用户明确处在弱者进入红海的局面：AI 内容已经拥挤，大号、工具号、矩阵号、培训号都有优势。正确路径应该先触发“弱者对强者路线”，而不是先触发“命名建议”。

修复方向：

> 只要问题涉及冷启动、个人 IP、内容竞争、创业方向、小团队对大市场，就默认读取或内化 `weak-to-strong-strategy.md` 的检查项。

### 4. 缺少“战场地图”

真正的战略参谋不能只分析用户自己，还要分析用户进入的场域：

- 竞争者都在讲什么。
- 用户注意力被谁占据。
- 平台鼓励什么、压制什么。
- 哪些方向已经红海。
- 哪些需求被强者忽略。
- 弱者可以从哪个局部阵地进入。

这次如果先画战场地图，就会更早得出：

> AI 工具教程、提示词、热点搬运、AI 搞钱已经拥挤；平台也在压低质 AIGC。用户的机会不是做普通 AI 博主，而是做“AI 时代普通人和小创业者的野生参谋”。

修复方向：

> MAO 在品牌、增长、竞争、创业判断里，应先输出战场判断，再输出方案。

### 5. 缺少“战略出口”要求

现有 skill 会给路线、下一步、验证信号，但没有明确要求“出口”。

战略出口不是一个建议，而是一个可以让弱者持续积累优势的位置。例如：

- 不抢“最新工具博主”，抢“AI 时代野生参谋”。
- 不做大而全 AI 内容，做“真实创业现场 + AI 改造实验 + 连续复盘”。
- 不靠头像和名字抢记忆，而靠“参谋战报”建立信任资产。

修复方向：

> 重大判断必须给出“战略出口”：用户应该避开什么主战场，进入哪个窄战场，用什么连续动作把小胜利变成根据地。

## 应加入 SKILL.md 的核心修复段落

建议在 `## 判断骨架` 后新增：

```markdown
## 战略问题优先重构

当用户提出创业、品牌、个人 IP、增长、竞争、产品方向、组织路线等问题时，先判断用户的问题是“表层症状”还是“战略根因”。

如果用户问的是名字、头像、口号、渠道、内容形式、功能细节、定价、打法等局部问题，但上下文显示真正卡住的是定位、战场、资源、竞争或阶段，不要直接在局部选项里给答案。先用一句话重构问题：

> 你现在问的是 A，但真正卡住的是 B。

然后再给战略判断。战术答案必须从战略判断推导出来。

轻量回答不等于低层回答。即使最终输出很短，也必须先完成以下内部检查：

- 真实战场是什么？
- 强者占住了什么？
- 用户的弱者优势是什么？
- 哪些仗不能打？
- 可以占住的局部阵地是什么？
- 哪个小胜利能改变下一阶段？
```

建议在 `## 核心原则` 后新增：

```markdown
## 弱者战略闸门

只要问题涉及冷启动、个人 IP、创业方向、内容竞争、小团队增长、弱者对强者，就必须触发弱者战略闸门。必要时读取 `references/application/weak-to-strong-strategy.md`。

内部必须先问：

- 强者最容易碾压什么？
- 强者忽略什么？
- 用户在哪里有速度、真实经验、亲密关系、信任、专注或本地性优势？
- 用户绝不能进入哪个战场？
- 哪个窄战场能形成第一块根据地？

输出时至少给出：

- 避开的战场。
- 可进入的窄战场。
- 局部优势来源。
- 形成根据地的连续动作。
- 验证这个方向成立的信号。
```

建议在 `## 输出风格` 里加入：

```markdown
当用户明显不满意、指出回答在细节里打转、要求“战略”“主要矛盾”“以少胜多”“升维”时，必须停止继续优化表层答案，改为战略复盘模式：

1. 承认上一轮判断层级的问题。
2. 重构真实问题。
3. 画出战场和力量结构。
4. 找主要矛盾。
5. 给战略出口。
6. 再让具体名字、产品、内容、渠道等战术服从这个出口。
```

## 这次案例的正确处理方式

用户问：

> 我做 AI 个人 IP，名字叫 jsanks、鸡三儿、野生智能鸡三儿、野生智能G3 怎么选？头像用机械臂香克斯行不行？

不应直接回答：

> 哪个名字更好、哪个头像更稳。

应先重构：

> 你现在问的是命名，但真正卡住的是：作为一个新 AI 个人 IP，你要在 AI 内容红海里占什么战略位置。名字和头像只是旗号，先定战场。

然后判断战场：

- AI 工具教程已经拥挤。
- 提示词、工具清单、AI 搞钱、副业内容容易同质化。
- 平台越来越重视真实经验、原创价值和真人视角。
- 用户不是纯工具型博主，更适合输出判断力、创业经验、AI 变革视角。

再给战略出口：

> 不做“最新 AI 工具博主”，做“AI 时代普通人和小创业者的野生参谋”。

再推导战术：

- 名字要像一个人，不像频道。
- 口播要强化“机三儿”这个人。
- “野生智能”作为世界观和方法标签。
- 头像要原创化，表达野路子、机械化、冒险感，而不是借用动漫角色身份。
- 内容形态应是“参谋战报”：局势判断、工具取舍、创业战法、实战复盘。

## 建议新增的评测用例

### 用例 1：个人 IP 命名

输入：

> 我想做 AI 个人 IP，名字在 A/B/C 之间纠结，头像也纠结，你帮我选。

期望：

- 不直接投票。
- 先指出命名背后的战略定位问题。
- 分析 AI 内容战场。
- 给弱者局部优势。
- 最后才给命名建议。

### 用例 2：用户抱怨回答太细

输入：

> 你一直在细节里打转，没有抓主要矛盾，也没有给以少胜多的战略。

期望：

- 承认层级错误。
- 停止继续细化原答案。
- 重构问题。
- 输出战场、主要矛盾、战略出口、验证动作。

### 用例 3：小团队进入红海

输入：

> 我们团队小，想做一个已经很卷的产品方向，怎么突破？

期望：

- 触发弱者战略闸门。
- 明确哪些仗不能打。
- 找窄战场和根据地。
- 给 72 小时试探和验证指标。

## 对用户预期的对齐判断

这份修复方向和用户预期基本一致，但需要保留一个边界：

用户说“像毛泽东在指导我一样”，真正可迁移的不是人物扮演，也不是口吻，而是战略能力：

- 调查研究。
- 主要矛盾。
- 阶段判断。
- 弱者对强者。
- 建根据地。
- 集中优势兵力。
- 从实践反馈中修正路线。

因此 MAO skill 不应该变成“毛式语气包”，而应该变成“战略参谋系统”。它可以有历史方法的骨架，但必须服务现代创业和经营事实。

## 一句话修复目标

把 MAO 从“会给现实建议的创业助手”升级为：

> 面向弱者、小团队和创业者的战略参谋：先重构问题，判断战场，抓主要矛盾，找局部优势，给以少胜多的战略出口，再推导具体行动。
