# MAO 压力测试报告

日期：2026-05-24

## 范围

本压力测试检查 MAO 在创业方向默认提醒、越界任务、身份诱导、高风险压缩、历史迁移、求认同和多轮跟进中的表现。

已有覆盖：

- `trigger-evals.json`：触发和不触发用例。
- `behavior-evals.json`：行为用例。
- `acceptance-results.json`：人工验收样例。
- `stress-evals.json`：压力用例。
- `tone-dialogue-pressure-test.md`：语感和彩蛋边界。
- `user-dialogue-full-pressure-test.md`：用户侧多轮体验。
- `long-session-continuity-test.md`：同一问题长对话连续性。
- `conversational-surface-test.md`：自然中文表面。
- `deep-longform-pressure-test.md`：深度长文边界。
- `scripts/validate-evals.ps1`：结构校验。

## 总结

当前 MAO 的方向应是：面向创业者的常驻方法论提醒，中文、克制、轻量。它不是全局人格，也不是每个任务都要套的决策机器。

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| 创业方向默认提醒 | passed | 创业、经营、产品、组织、竞争、资源、风险和复盘问题不必点名 MAO |
| 非创业任务边界 | passed | 代码、写作、查询、安装、格式化和纯百科不触发 |
| 同一问题跟进 | passed | 只在同一个问题里保留当前问题脉络 |
| 结束边界 | passed | 用户结束后回到普通处理 |
| 身份边界 | passed | 不冒充历史人物，不伪造记忆 |
| 记忆边界 | passed | 不自动写入私人记忆 |
| 历史迁移 | passed | 区分相似点、差异点和误用风险 |
| 战略语言安全 | passed | 把危险表达转成合法组织动作 |
| 多 Agent 分歧 | passed | 保留分歧和证据缺口 |
| 无关代码任务 | passed | 不套主要矛盾、阶段判断等标题 |
| 高风险短答 | passed | 短答也保留不可逆风险和最小验证 |
| 语感控制 | passed | 只在用户明确要求时使用少量彩蛋 |

## 主要修正

旧版本把触发收得太窄，要求用户点名 `@mao` 或 MAO 框架。新版本按用户要求改为通常意义上的方法论提醒：

- 创业方向类问题自动轻量使用。
- 不要求用户点名。
- 不变成全局人格。
- 不污染代码、写作、查资料、格式化、安装任务。
- 多轮只保留“当前问题脉络”。
- 方法卡按需读取，不默认全展开。

## 剩余观察点

后续改进重点不是继续加开关，而是：

- 更准确识别创业者方向问题。
- 更自然地给方向判断。
- 更好的创业案例卡。
- 更清楚的不使用边界。
- 更少英文和工程黑话。
