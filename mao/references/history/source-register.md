# 来源登记表

本文件登记 MAO 历史资料库可使用的来源家族。登记表不等于具体引文清单；具体案例卡仍要在卡片内标注使用到的来源类型、可信度、争议程度和可验证性。

## 来源家族

| 来源家族 | 默认等级 | 用途 | 主要风险 |
| --- | --- | --- | --- |
| 原文和同期讲话 | A | 判断公开立场、概念使用、当时论述重点 | 语境丢失、版本差异、后见解读 |
| 年谱、档案、当时记录 | A | 建立时间线、地点、事件顺序、公开行动 | 选择性记录、编纂口径 |
| 正式党史、军史、组织史材料 | B | 背景梳理、组织关系、战役和政策脉络 | 叙事立场、材料选择 |
| 严肃二手研究和可靠传记 | B | 多方解释、因果分析、争议梳理 | 研究流派偏差、资料依赖 |
| 参与者回忆录和口述史 | C | 人物压力、现场感、组织内部观感 | 记忆偏差、自我辩护、事后重构 |
| 争议性研究和回顾性论战 | D | 争议地图、反方解释、误用提醒 | 立场强、事实基础不稳 |
| 网络传闻、无出处引语、戏剧化故事 | E | 通常排除；最多用于说明不可靠 | 容易制造假权威 |
| 《毛泽东选集》全文与主题索引 | A- | 原文入口、概念定位、方法主题检索 | 版本差异、转换误差、语境误迁移 |

## 登记字段

新增具体来源时，按以下字段记录：

```text
来源名称：
来源家族：
默认等级：
适合支持：
不适合支持：
交叉验证要求：
争议备注：
适用案例：
```

兼容旧计划检查时，可映射为：

```text
【资料家族】
【类型】
【默认等级】
【适合支持】
【不适合支持】
【常见争议】
【使用注意】
```

## 使用约束

- 案例主干优先使用 A/B 来源。
- 人物血肉层可使用 C 来源，但必须显式降低置信度。
- D 来源只能帮助理解争议，不能单独支撑结论。
- E 来源不得进入案例主干。
- 同一案例如果只找到 C/D 来源，必须降级为“可疑案例”或“争议材料”，不能作为稳定方法卡。
- 《毛泽东选集》已按用户指定源仓库接入全文文本，使用时必须标注源仓库、提交号、源路径和转换方式；PDF/Office 条目只有在实际转换完成后才能当作全文来源。
