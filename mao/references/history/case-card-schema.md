# 历史案例卡格式

历史案例卡用于方法迁移，不用于复刻历史行动。每张卡必须把事实、解释、争议和现代迁移拆开。

## 必填字段

```text
案例名称：
案例类型：战役 / 组织 / 路线 / 失败 / 人物阶段 / 其他
时间范围：
来源摘要：
来源等级：A / B / C / D / E
争议程度：低 / 中 / 高
可验证性：高 / 中 / 低

历史背景：
主要矛盾：
次要矛盾：
阶段判断：防御 / 相持 / 反攻 / 阶段不明
力量结构：
路线选择：
执行方式：
短期结果：
长期影响：

正向解释：
反向解释：
争议点：
失败风险：

可迁移方法：
不可迁移边界：
适合现代场景：
不适合现代场景：
误用风险：
现代行动提示：
```

## 质量要求

- 没有来源等级，不进入案例库。
- 没有不可迁移边界，不允许用于现实建议。
- 没有误用风险，不允许用于历史迁移。
- 相似点和差异点必须同时出现。
- `主要矛盾` 必须能解释路线选择。
- `阶段判断` 必须说明为什么不是其他阶段。
- `力量结构` 至少包含己方、对方、可争取力量和环境约束。
- `正向解释` 与 `反向解释` 必须同时存在。
- `可迁移方法` 只能迁移结构和原则，不能迁移暴力、强制、违法、人格压制或历史特殊条件。
- `现代行动提示` 必须落到可观察行动，不能停在口号。

最小卡可以压缩，但不能少于：

```text
不可迁移边界：

```
