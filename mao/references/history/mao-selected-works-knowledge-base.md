## 收录边界

允许收录：

- 用户指定源仓库中的现成文本；
- 通过可复跑脚本和 Microsoft MarkItDown 从源仓库二进制文件转换出的文字；
- 文件级来源、提交号、转换方式和清单；
- 书目级信息、主题地图、方法索引和迁移边界。

不收录：

- 图片本体；
- 未成功 OCR/转换出的图片文字；
- 未登记来源的散落文本；
- 把原文直接替代现实判断的结论。

## 使用定位

《毛泽东选集》可作为 A 级“原文/公开论述”来源的一部分，用来判断：

- 概念如何被公开表述；
- 阶段判断和路线选择的论述方式；
- 调查研究、矛盾分析、群众路线、统一战线、持久战等方法的原始语境；
- 特定文章与历史阶段、组织任务、军事/政治问题之间的关系。

它不能单独证明：

- 现代商业、职业、组织决策的现实结论；
- 历史事件的完整因果；
- 作者私人动机；
- 争议历史问题的唯一答案。

## 引用规则

使用全文库时，按以下格式记录：

```text
【来源】M0rtzz/Selected-Works-of-MaoTseTung，source_path，commit
【转换】direct-text / word-com-text / OCR（如未来补充）
【来源等级】A（原文/公开论述）或 A-（版本信息不完整）
【能证明】该文本中的公开表述、概念用法、论述结构
【不能证明】现代问题的直接结论、私人动机、完整历史因果
【迁移边界】说明时代、组织形态、法律环境和现实条件差异
```

短引用必须服务于解释、评论或来源定位。长文回答优先使用概括、主题索引和方法迁移，不把原文整段复制成答案。

## 后续补全

PDF/Office/EPUB/MOBI/图片文件已经在 `MANIFEST.json` 中登记为 `available-for-markitdown-conversion`。需要补全时，用以下方式分批运行：

```powershell
python -m pip install -r requirements-markitdown.txt
powershell -ExecutionPolicy Bypass -File .\scripts\ingest-selected-works.ps1 -ConvertWithMarkItDown -ConvertPath "毛泽东文集" -MaxMarkItDownConversions 3
```

每批转换后检查 `MANIFEST.json`，只把实际完成转换的文件标记为 imported。
