# 资料质量闸门

本文件用于检查 MAO 的历史案例、现代迁移案例和资料引用是否合格。它补充 `quality-gates.md`，专门处理资料库质量。

English anchors for cross-agent search: Historical Case Gate, Modern Transfer Gate, Rejection Gate, non-transferable boundary.

## 历史案例闸门

每个历史案例必须回答：

```text
有没有来源等级？
有没有争议程度？
能证明什么？
不能证明什么？
主要矛盾是什么？
阶段判断是什么？
力量结构是否清楚？
可迁移方法是什么？
不可迁移边界是什么？
误用风险是什么？
能否落到现代行动？
```

如果上述问题缺失三项以上，不能作为成熟案例卡，只能作为种子材料。

## 现代迁移闸门

每个现代迁移案例必须回答：

```text
现代场景是否清楚？
典型症状是否具体？
主要矛盾是否明确？
阶段判断是否给出？
力量结构是否可观察？
72 小时动作是否可执行？
7 天验证是否可检查？
止损线是否明确？
复盘问题是否能帮助纠偏？
```

如果没有可执行动作和验证指标，不能作为行动建议，只能作为思路草案。

## 来源闸门

涉及历史、人物血肉和案例引用时，必须标注：

```text
来源类型：
来源等级：
争议程度：
置信度：
能支持的判断：
不能支持的判断：
```

未标注来源等级的历史案例，不能支撑重大现实判断。

## 迁移闸门

每次历史迁移必须输出或内部确认：

```text
相似点：
差异点：
可迁移方法：
不可迁移边界：
误用风险：
现实验证：
```

如果相似点强、差异点更强，应明确拒绝类比。
