# 认知骨架

本文件只给 MAO 一个轻量思考顺序。它不是强制输出模板，也不是全局模式。

## 基本顺序

```text
事实层 -> 不确定层 -> 矛盾层 -> 阶段层 -> 力量层 -> 路线层 -> 行动层 -> 反馈层
```

## 各层作用

| 层级 | 看什么 | 避免什么 |
| --- | --- | --- |
| 事实层 | 当前事实、资源、约束、直接证据 | 把口号、愿望、类比当事实 |
| 不确定层 | 假设、情绪、缺失证据、外部压力 | 证据很薄却装作确定 |
| 矛盾层 | 主要矛盾、次要矛盾、矛盾主要方面 | 把最吵的症状当根因 |
| 阶段层 | 防御、相持、反攻、阶段不明 | 资源不足时提前反攻 |
| 力量层 | 支持者、反对者、观望者、关键少数、消耗源 | 给人贴人格标签 |
| 路线层 | 选择战场、主攻方向、避战边界 | 只列行动清单，不做取舍 |
| 行动层 | 72 小时、7 天、30 天的小验证 | 用鼓舞代替验证 |
| 反馈层 | 预期信号和实际结果是否一致 | 证据变了还维护旧判断 |

## 使用尺度

普通问题不需要展示所有层。能自然说清楚时，只说：

1. 现在怎么看；
2. 为什么这么看；
3. 先做哪一步；
4. 什么动作最危险。

复杂问题才展开更多层。

## 当前问题脉络

多轮跟进同一个 MAO 问题时，可以轻量保留：

- 已知事实
- 关键假设
- 未回答问题
- 当前阶段
- 暂定路线
- 止损条件
- 下次复盘点

这只是当前问题的临时脉络，不是长期记忆，不要带到无关任务。

## 证据纪律

判断要跟证据强度匹配：

- 事实足够区分至少两条路线，才能给路线判断。
- 假设要能被验证。
- 主要矛盾要能解释表面症状。
- 阶段判断要看资源、证据、执行力和可逆性。
- 行动要有指标、止损和复盘时间。

证据弱时，先给最小调查动作，不要急着给最终路线。
