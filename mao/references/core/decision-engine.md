# 判断备忘

这个文件用于重大问题的内部检查。它不是必须展示给用户的模板。用户没有要求结构化记录时，优先用自然中文回答。

## 内部字段

```yaml
问题类型:
已知事实:
关键假设:
情绪或压力:
证据缺口:
主要矛盾:
次要矛盾:
矛盾主要方面:
转化条件:
阶段:
力量结构:
战略:
战术:
避战边界:
验证指标:
止损条件:
复盘时间:
置信度:
下一步试探:
```

## 字段说明

| 字段 | 说明 |
| --- | --- |
| 问题类型 | 先判断这是快速建议、重大决策、复盘、组织问题，还是事实不足 |
| 已知事实 | 只写当前问题里已经出现的事实 |
| 关键假设 | 写出可能错的判断 |
| 情绪或压力 | 记录急迫、害怕、兴奋、羞耻、求认同等会影响判断的因素 |
| 证据缺口 | 哪些事实一旦不同，路线就会改变 |
| 主要矛盾 | 真正卡住问题的结构性瓶颈 |
| 次要矛盾 | 重要但不是主攻方向的矛盾 |
| 矛盾主要方面 | 当前哪一方占主导 |
| 转化条件 | 什么变化会改变阶段或路线 |
| 阶段 | 防御期、相持期、反攻期、阶段不明 |
| 力量结构 | 可观察的角色、利益、约束和消耗源 |
| 战略 | 选哪个战场，走哪条路线 |
| 战术 | 需要时给 72 小时、7 天、30 天动作 |
| 避战边界 | 哪些仗不要打，哪些钱和精力不要花 |
| 验证指标 | 什么事实能证明路线在推进 |
| 止损条件 | 继续、暂停、停止、转向的条件 |
| 复盘时间 | 什么时候回看结果 |
| 置信度 | 只在有用时给粗略置信度 |
| 下一步试探 | 最小、可逆、能改变下一轮判断的行动 |

## 输出规则

这份备忘是为了保护判断质量，不是为了把回答变复杂。除非用户要“记录”“表格”“决策档案”，否则不要原样展示。
