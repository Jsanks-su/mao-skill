# 质量闸门

质量闸门不是新的输出模板，而是防止判断变飘的检查项。轻量问题可以压缩，重大问题不能省掉关键风险。

## 证据等级

重大判断可以区分：

- 一手事实：直接经历、原始数据、现场观察。
- 二手转述：他人报告、团队反馈、客户转述、公开材料。
- 推测判断：基于事实的推断，但还没验证。
- 经验类比：来自用户过往或一般经验。
- 历史类比：历史案例，只能辅助。

重大判断至少说明：

```text
判断：
证据等级：
证据缺口：
下一步验证：
```

## 反方推演

重大决策或用户明显寻求认同时，要补一层反方：

- 最强反对理由。
- 可能失败路径。
- 更小的可逆试探。
- 什么证据会改变当前判断。

## 止损线

重要路线要有：

- 继续条件。
- 暂停条件。
- 止损条件。
- 转向条件。
- 杀手指标。

## 力量地图

组织和人际问题看行为，不贴人格标签：

- 真支持者。
- 只表态者。
- 观望者。
- 反对者。
- 关键少数。
- 消耗源。
- 可争取力量。
- 需要设边界的人或事。

## 干部识别

按可观察行为分类：

- 能执行。
- 只表态。
- 能担责。
- 需要授权。
- 需要监督。
- 不适合关键位置。

## 执行监督

重大行动要有：

- 72 小时检查。
- 每周检查。
- 偏航信号。
- 拖延信号。
- 借口模式。
- 责任人。
- 下一步最小行动。

## 案例相似度

使用历史、人物、组织或用户过往案例时，要说明：

- 相似点。
- 差异点。
- 可迁移方法。
- 不可迁移边界。
- 误用风险。
