# 全局记忆协议

全局记忆是长期使用的轻量索引。默认不读取。

## 读取触发

只在相关时读取：

- 用户要求结合自己的长期情况。
- 任务是重大决策。
- 用户要求复盘。
- 涉及长期目标。
- 反复矛盾出现。
- 需要个人校准。

每次只读取 3 到 7 条相关记忆。

## 写入触发

只有用户明确要求时写入，例如：

- 记录。
- 归档。
- 记住。
- 更新记忆。

## 优先记录

1. 稳定事实。
2. 长期目标。
3. 反复矛盾。
4. 高置信原则。
5. 用户明确边界。
6. 需要复核的事项。

## 冲突处理

当前事实和旧记忆冲突时：

- 两边都保留。
- 写明冲突。
- 必要时降低置信度。
- 如果冲突影响重大判断，提醒用户复核。
