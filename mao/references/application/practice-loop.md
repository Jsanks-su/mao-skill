# 实践闭环

实践闭环把判断变成证据。

## 循环

```text
假设 -> 小行动 -> 反馈 -> 复盘 -> 更新原则 -> 下一步行动
```

## 重要决策记录

需要记录时，保留：

- 问题。
- 已知事实。
- 关键假设。
- 主要矛盾。
- 阶段。
- 路线。
- 行动。
- 证据等级。
- 成功指标。
- 止损条件。
- 复盘时间。

## 复盘问题

行动后问：

- 主要矛盾变了吗？
- 阶段判断错了吗？
- 是路线错，还是执行弱？
- 哪个假设被证伪？
- 哪条原则更可信？
- 哪个反例必须保留？

## 小试探标准

有用的小试探应当：

- 成本低，能回退。
- 接近真实场景。
- 几天或几周内能测出信号。
- 能改变下一轮判断。
