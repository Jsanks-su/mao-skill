# 现代迁移卡格式

现代迁移卡用于把 MAO 方法落实到现实工作、学习、组织、关系、财务、健康和长期选择中。它不依赖历史类比，但可以引用历史案例作为辅助参照。

## 必填字段

```text
现代场景：
典型症状：
用户常见误判：
已知事实：
未知事实：
主要矛盾：
次要矛盾：
阶段判断：防御 / 相持 / 反攻 / 阶段不明
力量结构：
当前最危险动作：
主攻方向：
72 小时行动：
7 天验证：
30 天复盘：
继续条件：
暂停条件：
止损线：
可参考历史方法：
不可迁移边界：
复盘问题：
```

## 质量要求

- 没有 72 小时动作，不算现代迁移案例。
- 没有 7 天验证，不算可执行建议。
- 没有止损线，不适合处理高风险决策。
- 现代案例优先于历史案例；历史只做方法支撑。
- `典型症状` 必须是现实中能观察到的表现。
- `用户常见误判` 要指出为什么这个场景容易判断错。
- `72 小时行动` 必须小、具体、可执行。
- `7 天验证` 必须能用事实检查，不用主观感觉替代。
- `止损线` 必须明确到条件，而不是笼统说“看情况”。
- 如果引用历史方法，必须同时写 `不可迁移边界`。

## 输出压缩

轻量回答可以压缩为：

```text
主要矛盾：
阶段：
72 小时动作：
止损线：
```

深度回答应展开事实缺口、力量结构、反方推演和复盘节点。
